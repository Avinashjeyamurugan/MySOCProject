# MySOCProject: Security Operations & Monitoring

Welcome to my SOC project repository! This repository contains security configurations, detection dashboards, and log analysis scripts built to simulate and monitor security events in a Security Operations Center (SOC) environment.

---

## 📂 Repository Contents

* **`ssh_security_monitoring.xml`**: A custom dashboard configuration designed to track, aggregate, and visualize SSH authentication events, helping analysts identify potential brute-force attacks and unauthorized access attempts.

---

## 🛠️ Tools & Technologies Used
* **SIEM / Log Analysis**: Splunk / ELK Stack (adjust based on your tools)
* **Network Protocol Analysis**: Wireshark
* **Protocols & Services**: SSH, TCP/IP

---

## 🚀 Key Objectives
1. **Threat Detection**: Monitor authentication logs for suspicious activities such as repeated failed login attempts.
2. **Dashboard Visualization**: Centralize security metrics to reduce Mean Time to Detect (MTTD).
3. **Incident Response**: Build repeatable frameworks for analyzing malicious traffic and unauthorized access vectors.
